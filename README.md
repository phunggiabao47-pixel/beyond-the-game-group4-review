# BEYOND THE GAME — DEMO 1 · STABLE

Website thuyết trình ELL1/2026, Group 04, Hoa Sen University.

## Deploy lên Vercel (static)
- Repository GitHub chỉ cần **index.html** tại thư mục gốc.
- Vercel: Framework Preset = Other; Root Directory = ./; không cần npm, build command hoặc thư mục assets.
- Nếu cần kiểm thử an toàn, dùng project Review độc lập trước; chỉ thay index.html ở project chính sau khi duyệt.

## Tính năng
- 17 cảnh (12 slide nội dung/credits/kết thúc + module bonus 3 vòng).
- EN / VI, mũi tên trái-phải, Space, nút F fullscreen tùy trình duyệt, vuốt ngang trên điện thoại.
- 50 phiếu; ảnh và logo do nhóm gửi đã nhúng trực tiếp trong một file HTML.

## Chưa hoàn tất trong bản DEMO 1
- Tên/vai trò thật của thành viên và đáp án của 3 ảnh quiz: chưa được nhóm cung cấp, không tự suy đoán.
- Thành tích các đội tuyển Việt Nam năm 2026: chờ xác minh nguồn chính thức.
- QR cuối bài: chỉ tạo sau khi URL bản chính thức đã duyệt.
- Website sử dụng hình ảnh được nhóm cung cấp cho mục đích demo. Kiểm tra quyền sử dụng trước khi công bố công khai.
